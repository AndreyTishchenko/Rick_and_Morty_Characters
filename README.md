# Rick and Morty Characters

Frontend application for browsing characters from the Rick and Morty API.

The project allows users to view character information, search characters, and explore data from the Rick and Morty universe.

## Features

- Character list
- Character details
- Search functionality
- API integration
- Responsive UI

## Tech Stack

- JavaScript
- React
- CSS
- REST API

## Installation

```bash
npm install
```

## Run Project

```bash
npm start
```

## API

Data provided by:
https://rickandmortyapi.com/
